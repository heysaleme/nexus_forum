# Nexus Forum

Локальный React/Vite проект с демо-данными в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite в терминале. Обычно это `http://localhost:5173/`.

## Что внутри

- Проект больше не зависит от Base44 для локального запуска.
- Данные хранятся локально в браузере через `localStorage`.
- При первом запуске автоматически создаются демо-пользователи, сообщества, посты, чат и уведомления.

## Полезно

- Демо OTP-код для регистрации: `123456`
- Если хочется сбросить локальные данные, очистите `localStorage` в браузере.
- Рекомендуемая версия Node: `22`
